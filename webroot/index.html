Texture groups

Switch a group off to leave it original. Play one match first so this list can fill in.

A group is one texture format and size. Walls and floors can share a group, so switching it off affects both.

Skip list (advanced)

One group per line. Use format size or format width height. Textures in these groups stay original.

Format is the number from the log (for example 37496 is ETC2 RGBA). Tap Apply for CODM after saving.
