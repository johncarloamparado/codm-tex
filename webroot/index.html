Texture groups

Turn a group off to leave those textures original. Play one match first so the list can fill in.

A group is one format and size. Walls and floors can share a group, so switching it off affects both.

Skip list

One group per line. Use format size or format width height. Textures in these groups stay original. A few built-in skips are always on and cannot be removed here.
